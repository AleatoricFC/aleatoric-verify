AleatoricFC — Proof of Bets

Every bet is cryptographically locked before kick-off and published here. This page checks the signatures live, in your browser. Nothing to install.

Verifying…

What this proves. Each day, the full bet list (outcome, price, stake) is hashed and signed with a private key the moment it's placed — then the signature is posted publicly, before any match starts. The next day the full bets are revealed. Because the signature only matches the exact bets that were locked in, they can't be edited, cherry-picked, or backdated after results come in.

The chain. Every day links to the previous one. The single head hash below covers the entire history — if any past day were changed, added, or removed, the head would change. The current head is pinned in the Telegram channel bio.

Prefer to check it yourself from scratch? Clone the repository and run python verify.py — it does the same checks offline with only pip install cryptography.
